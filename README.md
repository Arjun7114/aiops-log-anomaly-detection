\# AIOps: Log Anomaly Detection using Isolation Forest



Detecting anomalies in system logs using unsupervised machine learning,

replacing brittle regex-based parsing with template mining.



\## Status

🚧 In progress



\## Tech Stack

Python, scikit-learn (Isolation Forest), Drain3, pandas



\## Project Structure

\- `data/` — log datasets

\- `src/` — source code

\- `notebooks/` — exploration

\- `results/` — outputs and plots
